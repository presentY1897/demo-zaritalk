## 기간 중복 판정 (`features/lease/rules.ts`)

| 항목 | 규칙 |
|---|---|
| 경계 | **양끝 포함**(closed interval). `endDate` 는 "마지막 거주일"이라 다음 계약은 그 **다음 날**부터 |
| 대상 | 같은 호실의 **진행 중 계약**(`PENDING_TENANT`·`ACTIVE`)만 |
| 제외 | `ENDED`·`CANCELLED` 이력은 겹쳐도 막지 않는다 — 계약 이력은 지우지 않고 남기므로(T1.1 삭제 규칙), 잘못 등록한 계약을 종료로 정리한 뒤 같은 기간에 다시 등록할 수 있어야 한다 |
| 자기 자신 | `PATCH` 로 기간을 바꿀 때는 `excludeLeaseId` 로 뺀다 |
| 결과 | 겹치면 **409 `CONFLICT`** (겹치는 계약의 기간을 문구에 담는다) |

```ts
periodsOverlap(a, b)      // a.start <= b.end && b.start <= a.end
findOverlappingLease(period, leases, { excludeLeaseId? })   // 겹치는 첫 계약 or null
```

## 첫 청구 대상 월 (`resolveInitialChargeMonth`)

- 기본은 **당월**(KST). 계약이 다음 달 이후 시작이면 **계약 시작월**로 민다.
- 대상 월이 계약 종료월을 넘으면 **청구를 만들지 않는다**(이미 끝난 계약을 뒤늦게 입력한 경우).
- 크론은 `ACTIVE` 만 훑으므로(T1.4) **`PENDING_TENANT` 계약의 첫 청구는 여기서만** 생긴다.

## 계약 종료(ENDED) 규칙

| 항목 | 규칙 |
|---|---|
| 종료일 | `endDate` 를 함께 보내면 그 날로, **생략하면 오늘(KST)** 로 당긴다(계약 시작일보다 이르면 시작일) |
| 종료일 **이후** 청구 | `dueDate > endDate` **이고 납부 기록이 하나도 없는** 청구는 **삭제**한다 — 받을 근거가 없는 달이다 |
| 종료일 **이내** 미납 청구 | **그대로 남긴다.** 계약이 끝나도 채권은 남는다 — 보증금 정산·환급(T2.3)이 이 청구를 본다 |
| 납부 기록이 있는 청구 | 종료일 이후여도 **지우지 않는다**(이미 받은 돈의 근거를 없애지 않는다) |
| 이후 청구 생성 | 크론은 `ACTIVE` 만 훑으므로 종료 뒤에는 새 청구가 생기지 않는다 |
| 호실 상태 | 진행 중 계약이 사라지므로 그리드가 자동으로 **공실**이 된다(`deriveUnitStatus`) |
| 재종료 | 이미 `ENDED`·`CANCELLED` 인 계약을 또 종료하면 **409** |

응답의 `settlement` 가 "몇 건을 지웠고 미납 몇 건·얼마가 남았는지"를 알려 준다.
`status` 로는 **`ENDED` 만** 받는다 — `ACTIVE` 전환(세입자 수락)은 T1.3 소유고 임대인이 임의로 계약을 성립시키면 안 된다.
