# T1.2 계약 등록·관리

> Phase 1 · 상태: ⬜ · [목차](./README.md)

| 라우트 | 화면·기능 |
|---|---|
| `/landlord/leases/new` | 계약 등록 — 호실 선택, 세입자 이름·전화번호, 보증금·월세·관리비·납부일·기간·연체이율. 등록 즉시 PENDING_TENANT |
| `/landlord/leases/[id]` | 계약 상세 — 조건 요약, 연결 상태, 수납 탭(T1.5), 고지서 발송(T1.7), 종료 처리 |

| 엔드포인트 | 동작 |
|---|---|
| `GET·POST /api/leases` | 목록·등록 — 등록 시 당월 RentCharge 즉시 생성 |
| `GET·PATCH /api/leases/[id]` | 상세·수정·종료(ENDED) |

- **완료 기준**
  - [ ] 계약 등록 → PENDING_TENANT + 당월 청구 자동 생성
