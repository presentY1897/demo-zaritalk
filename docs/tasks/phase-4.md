# Phase 4 — 커뮤니티·실거래가

> 스펙: [§10 커뮤니티](../specs/10-community.md) · [§11 실거래가](../specs/11-real-transaction.md) · [§13 백오피스](../specs/13-admin.md)
> 선행 조건: 공공데이터포털 실거래가 키(사용자)

## ⬜ T4.1 커뮤니티 보드

- **내용**: posts·comments·likes API + `/community`(지역 선택, 최신/인기 탭, 무한 스크롤), `/community/write`, `/community/[postId]`
- **완료 기준**: 글·댓글·좋아요가 화면에서 완주, 인기 탭이 likeCount 순 정렬, 프로필 유형 배지 표시
- **최소 테스트**: 커서 페이지네이션 — 경계·중복 없음, 좋아요 토글 멱등(2회 = 원상태), likeCount 비정규화 일치
- **통합 테스트**: E2E — 글 작성 → 다른 계정으로 좋아요·댓글 → 인기 탭 순위 반영

## ⬜ T4.2 신고·모더레이션

- **내용**: `POST /api/reports` + 어드민 `/reports`(대기 목록, 대상 미리보기, 블라인드/기각), soft delete 표시
- **완료 기준**: 신고 → 어드민 큐 → 블라인드 시 커뮤니티에서 블라인드 표시로 전환, 처리자·시각 기록
- **최소 테스트**: 중복 신고 처리, 블라인드된 글 목록 노출 규칙(작성자에겐 표시 등)
- **통합 테스트**: **E2E** 신고 → 어드민 블라인드 → 일반 사용자 화면에서 본문 숨김 확인

## ⬜ T4.3 실거래가 수집 배치

- **내용**: 국토부 API 클라이언트 + `POST /api/deals/sync`(월별 수집→upsert, 만원 단위), 크론 등록, 어드민 수동 트리거
- **완료 기준**: 특정 시군구 1개월분 수집이 멱등(재실행해도 중복 없음)
- **최소 테스트**: **수집 핵심.** ①XML/JSON 파싱(면적·층·금액 필드) ②만원 단위 보존 ③upsert 멱등 ④API 오류 시 부분 실패 격리. 외부 API는 fixture mock
- **통합 테스트**: 실키 1회 호출 태그드 테스트(키 없으면 skip)

## ⬜ T4.4 실거래가 조회·알림

- **내용**: `GET /api/deals` + `/deals`(시군구·거래유형 탭, 단지 검색, 추이 미니 차트), transaction-alerts CRUD + 구독 시트, 수집 시 신규 거래 알림톡 시뮬
- **완료 기준**: 조회·필터·구독이 화면에서 완주, sync 후 구독자에게 MessageLog 생성
- **최소 테스트**: 알림 매칭 — 지역+단지+유형 조합 필터, 구독 유니크 제약
- **통합 테스트**: API — sync(fixture) → 구독자 알림 생성 검증
