# T1.4 원장 엔진 (청구 생성·이월·연체)

> Phase 1 · 상태: ⬜ · [Phase 구성](../PHASES.md)

- **원장 규칙** (순수 함수 모듈로 구현)
  - 매일 크론이 ACTIVE 계약의 당월 청구 생성(멱등). `totalDue = 월세 + 관리비 + 전월 이월 + 연체료`
  - 납부(수동·가상·카드)는 RentPayment 행으로 쌓고 `paidAmount` 누적 — 0<paid<total → PARTIALLY_PAID, 도달 → PAID
  - 납부일 경과 → OVERDUE. 미납 잔액은 익월 청구 `carriedOverAmount`로 이월, `lateFeeRatePct` 있으면 연체료 일할 가산
- **크론**: `POST /api/cron/daily`(시크릿 헤더 인증) — 청구 생성·연체 전환·이월·연체료 + 만기 90일 전 CONTRACT_EXPIRY 알림 1회. 어드민 수동 트리거 버튼 제공
- **완료 기준**
  - [ ] 크론 2회 연속 실행에도 중복 청구·중복 만기 알림 없음(멱등)
  - [ ] 시드 기준 상태 전이가 규칙대로
- **테스트** — 최소(**핵심**): ①멱등 생성 ②부분납 상태 전이 ③이월 금액 계산 ④연체료 일할(rate null=0) ⑤말일 보정(paymentDay 31→2월) ⑥크론 무인증 401 / 통합: 크론 실행 → 신규 월 청구+OVERDUE 전환 DB 검증
