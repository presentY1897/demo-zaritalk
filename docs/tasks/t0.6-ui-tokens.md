# T0.6 packages/ui 디자인 토큰

> Phase 0 · 상태: ✅ · [Phase 구성](../PHASES.md)

- **내용**: 자리톡 옐로 브랜드 톤([C1](../DECISIONS.md#-c1-ui-톤-2026-09-01-확정)) PandaCSS 토큰 — 컬러·타이포·spacing·radius·shadow + 기본 컴포넌트(Button·Input·Sheet·Badge·Card)
- 토큰은 `packages/ui/src/theme.ts` **한 곳에만** 정의하고, web·admin 의 `panda.config.ts` 가 `theme: { extend: zariThemeExtend }` 로 그대로 spread 한다(앱 쪽 중복 선언 없음)
- 공용 컴포넌트는 `cva` 로 variant 를 정의하고, 앱 panda 의 `include` 에 `packages/ui/src` 를 넣어 **모든 variant 조합 CSS 가 앱 빌드에서 정적 추출**된다

## 파일

| 파일 | 역할 |
|---|---|
| `packages/ui/src/theme.ts` | 원시 토큰·semantic 토큰·textStyle·keyframes·globalCss. 앱이 spread 하는 `zariThemeExtend`·`zariUiIncludeGlob`·`zariGlobalCss` 를 내보낸다 |
| `packages/ui/panda.config.ts` | @zari/ui 전용 **codegen 전용** 설정. 컴포넌트가 쓰는 `styled-system/css`(css·cva·cx)를 패키지 안에 생성한다. CSS 는 앱이 뽑는다 |
| `packages/ui/turbo.json` | `build`(= `panda codegen`) 의 outputs 를 `styled-system/**` 로 지정 — 캐시 히트 시 생성물이 복원되게 |
| `packages/ui/src/components/recipes.ts` | cva 정의 7종(button·input·badge·card·sheetOverlay·sheetPanel·spinner). React 비의존 순수 모듈 |
| `packages/ui/src/components/*.tsx` | Button·Input·Sheet·Badge·Card·Spinner |
| `packages/ui/src/components/index.ts` | 컴포넌트·타입·recipe re-export (`src/index.ts` 가 이 파일을 그대로 내보낸다) |
| `packages/ui/src/components/recipes.test.ts` | variant 조합 단위 테스트 11개 |
| `apps/{web,admin}/panda.config.ts` | 같은 preset 소비 — `include` 에 `packages/ui/src`, `theme.extend` 에 `zariThemeExtend`, `globalCss` 에 `zariGlobalCss` |
| `apps/{web,admin}/src/app/page.tsx` | 하드코딩 색상 제거 + 새 컴포넌트로 재작성 |

## 컴포넌트 API

| 컴포넌트 | props |
|---|---|
| `Button` | `variant` primary·secondary·ghost·danger / `size` sm·md·lg / `fullWidth` / `loading` / `startIcon`·`endIcon` / `disabled` + 기본 button 속성. `type` 기본 `"button"`, `loading` 이면 라벨 자리를 유지한 채 스피너 + `aria-busy` |
| `Badge` | `tone` success·warning·danger·info·neutral·brand / `size` sm·md / `solid` |
| `Card` | `padding` none·sm·md·lg / `interactive` / `as`. 보조: `CardHeader({title, aside})` · `CardBody` |
| `Input` | `label` · `helper` · `error` · `size` sm·md·lg · `required` + 기본 input 속성. `error` 가 있으면 `aria-invalid` + `role="alert"` 문구를 `aria-describedby` 로 연결 |
| `Sheet` | `open` · `onClose` · `title` · `description` · `footer` · `closeOnOverlayClick`. 하단 슬라이드업 + 딤, ESC·딤 클릭 닫기, 포커스 트랩·복귀, body 스크롤 잠금, 폭은 `sizes.shell`(480px) 상한 |
| `Spinner` | `size` sm·md·lg (`currentColor` 상속) |
