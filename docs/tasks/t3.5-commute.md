## 대중교통은 모킹 ([D9](../DECISIONS.md#-d9-대중교통-통근시간--모킹-2026-09-02-확정))

- **차량**: 카카오모빌리티 REST 실연동 (`KAKAO_REST_API_KEY` 설정 완료)
- **대중교통**: 모의 제공자. ODsay 키가 생기면 제공자 구현만 교체한다.
- 제공자를 인터페이스로 두고 `car`/`transit` 두 구현을 넣는다. 모의 값은 **화면에 모의임을 표시**하고, 좌표 기반 **결정적** 함수여야 한다 — 같은 (매물, 근무지) 쌍이 매번 같은 값을 내야 `CommuteCache` 와 테스트가 흔들리지 않는다.
- 카카오모빌리티 REST 에는 대중교통 경로 API 가 없다(자동차·도보만). 대중교통을 실연동하려면 ODsay 가 필요하다.
