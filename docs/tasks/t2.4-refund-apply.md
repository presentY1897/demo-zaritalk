# T2.4 환급 신청

> Phase 2 · 상태: ⬜ · [목차](./README.md)

| 라우트 | 화면·기능 |
|---|---|
| `/tenant/refund/apply` | 내 계약 자동 채움(또는 수동), 소급 기간 선택, 서류 업로드(계약서·등본 슬롯, D3 저장소), DRAFT 임시저장 → 제출 |
| `/tenant/refund` | 상태 스테퍼(제출→심사중→보완요청/승인/반려→완료), 보완 시 추가 업로드, 심사 코멘트 |

| 엔드포인트 | 동작 |
|---|---|
| `GET·POST /api/refunds` | 목록·생성(DRAFT), `PATCH /[id]` 수정, `POST /[id]/submit` 제출 |
| `POST /api/uploads` | 서류 업로드(D3), 메타를 documents(Json)에 기록 |

- **완료 기준**
  - [ ] 임시저장→제출→상태 추적 완주, 보완요청 시 추가 업로드
- **테스트** — 최소: 제출 시 필수 서류 검증 · DRAFT 아닌 신청 수정 거부 · 업로드 타입·크기 제한
