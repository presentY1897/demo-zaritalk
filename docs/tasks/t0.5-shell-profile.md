## 셸 구조 (route group)

```
apps/web/src/app/
├─ layout.tsx                 문서 골격 + Providers 만 (480px 제한을 여기서 걷어냈다)
└─ (app)/                     ← 셸 그룹. 그룹 이름은 URL 에 안 들어간다
   ├─ layout.tsx              AppShell = 480px 중앙 정렬 + 하단 탭바 + 데스크톱 바탕
   ├─ page.tsx                `/` 랜딩 · 로그인 시 프로필 홈으로 redirect  ← 기존 app/page.tsx 를 git mv
   ├─ search/page.tsx         `/search` (T3.2, 비로그인 허용)
   └─ (protected)/            ← 로그인 필수 그룹
      ├─ layout.tsx           requireUser() → 비로그인이면 /login 리다이렉트
      ├─ me/page.tsx          `/me` 마이페이지 (T0.5 구현)
      ├─ landlord/…, tenant/…, realtor/…, master/…, community/  탭 목적지 플레이스홀더
```

## 활성 프로필 상태 흐름 (쿠키 ↔ atom)

```
[원본]  쿠키 zari_profile (= ACTIVE_PROFILE_COOKIE, httpOnly 아님, lib/auth/session.ts)
   ↓ 서버: (app)/layout.tsx 가 getCurrentUser() + getActiveProfile() 로 읽어
   ↓        AppShell props(profiles, activeProfileId) 로 내려준다
[사본]  Jotai atom (activeProfileIdAtom / profilesAtom)  ← ActiveProfileHydrator 가 하이드레이트
   ↓ TabBar·전환 시트는 atom 만 구독한다
[전환]  시트에서 선택 → POST /api/profiles/active
          ├ 서버: 쿠키 갱신 (다음 요청·새로고침·SSR 이 이 값을 본다)
          └ 클라: 응답으로 atom 갱신 → 탭바가 **새로고침 없이** 그 자리에서 바뀐다
             + router.refresh() 로 서버 컴포넌트(마이페이지 표기 등)만 소프트 갱신
```

- 레이아웃은 네비게이션마다 다시 렌더되지 않으므로(Next 16) 즉시 반영은 atom 이 맡는다.
- 하이드레이터는 첫 렌더에 `useHydrateAtoms`, 이후에는 **서버 값이 실제로 바뀔 때만** atom 을 덮어쓴다(전환 직후의 낙관적 값이 오래된 서버 값에 되돌아가지 않게).
- 로그아웃은 전체 페이지 이동(`window.location`)이라 atom·쿼리 캐시가 통째로 버려진다.

## 라우트·API

| 라우트/API | 동작 |
|---|---|
| `/me` | 마이페이지 — 프로필 전환 시트(+새 유형 추가), 내 정보, 로그아웃 |
| `POST /api/profiles/active` | 활성 프로필 전환(쿠키 갱신) |

- 「새 유형 추가」는 T0.4 의 `/onboarding` 으로 링크만 걸어 뒀다. T0.4 머지 전에는 404 가 정상이다(`/login` 도 같다).
- 로그아웃은 `POST /api/auth/logout`(T0.3) → `/login` 이동.

### `POST /api/profiles/active`

```jsonc
// 요청
{ "profileId": "cmf0…" }

// 200 — GET /api/me 와 같은 모양. 쿠키 zari_profile 이 갱신된다
{ "user": { … }, "profiles": [ … ], "activeProfile": { "id": "cmf0…", "type": "TENANT", … } }
```

| 실패 | status · code |
|---|---|
| 비로그인 | 401 `UNAUTHORIZED` |
| `profileId` 누락·빈 문자열 | 400 `VALIDATION_ERROR` |
| **타인 프로필 id** | 403 `FORBIDDEN` |
| 존재하지 않는 프로필 id | 404 `NOT_FOUND` |

응답을 `GET /api/me` 와 같은 모양으로 맞춰 클라이언트가 프로필 목록·활성 프로필을 한 번에 갱신한다.
