# Phase 2 — 세입자 결제·환급·민원

> 선행: 토스페이먼츠 테스트 키(사용자), D3(업로드 저장소) 결정
> 모델: TossPayment · RentPayment · RefundApplication · Complaint · ComplaintMessage

## ⬜ T2.1 토스 결제 API

- **플로우**: ①`checkout`으로 orderId 발급(READY, 금액=청구 잔액) ②토스 위젯 결제 → successUrl 리다이렉트 ③`confirm` — 서버 금액 위변조 검증 → 토스 승인 → DONE ④같은 트랜잭션에서 RentPayment(CARD) 생성 → 청구 재계산 → 임대인 원장 즉시 반영

| 엔드포인트 | 동작 |
|---|---|
| `POST /api/toss/checkout` | orderId 발급 + TossPayment(READY) |
| `POST /api/toss/confirm` | 금액 검증 → 승인 → DONE + RentPayment 반영, 실패 시 FAILED |
| `POST /api/toss/webhook` | 상태 변경 수신(취소 등) — raw 저장 후 동기화 |

- **완료 기준**
  - [ ] 테스트모드 결제 승인 → 임대인 원장에 CARD 납부 즉시 반영
- **테스트** — 최소(**핵심**, 토스 mock): ①금액 위변조 거부 ②DONE orderId 재승인 거부 ③승인 실패 시 FAILED·RentPayment 미생성 ④webhook 취소 동기화 / 통합: 실제 토스 테스트 API confirm 1회(키 없으면 skip)

## ⬜ T2.3 환급 계산기

- **계산 규칙**: 월세 세액공제 — 총급여 5,500만 이하 17% / 5,500~8,000만 15% / 초과 대상 외, 공제 대상 월세 연 1,000만원 한도, 5년 소급 합산. 연도별 상수 테이블 관리, "실제 세법 자문 아님" 화면 표기

| 라우트/API | 동작 |
|---|---|
| `/refund/calculator` | **비로그인 허용(SEO·유입)** — 연 총급여·월세·기간 입력 → 연도별 산출+합계, 「신청하기」 CTA(비로그인이면 가입 유도) |
| `POST /api/refund/calculate` | 계산 결과 반환(저장 안 함) |

- **완료 기준**
  - [ ] 입력 → 연도별 내역+합계 표시, CTA 동작
- **테스트** — 최소(**핵심**): 공제율 경계값(5,500/8,000) · 한도 컷 · 소급 연도 산정 · 부분 연도
