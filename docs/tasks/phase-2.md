# Phase 2 — 세입자 결제·환급·민원

> 스펙: [§5 자리페이](../specs/05-zaripay.md) · [§6 환급](../specs/06-refund.md) · [§9 민원(전반)](../specs/09-complaint-workorder.md) · [§13 백오피스](../specs/13-admin.md)
> 선행 조건: 토스페이먼츠 테스트 키(사용자), D3(업로드 저장소) 결정

## ⬜ T2.1 토스 결제 API

- **내용**: `POST /api/toss/checkout`(orderId 발급, READY), `POST /api/toss/confirm`(금액 검증→승인→RentPayment 반영, 트랜잭션), `POST /api/toss/webhook`
- **완료 기준**: 테스트모드 결제가 승인되고 임대인 수납 원장에 CARD 납부로 즉시 반영
- **최소 테스트**: **결제 핵심.** ①confirm 금액 위변조 거부 ②이미 DONE인 orderId 재승인 거부(멱등) ③승인 실패 시 FAILED 기록·RentPayment 미생성 ④webhook 취소 → 상태 동기화. 토스 API는 mock
- **통합 테스트**: confirm까지를 실제 토스 테스트 API로 1회 검증하는 태그드 테스트(키 없으면 skip)

## ⬜ T2.2 결제 UI

- **내용**: `/tenant/pay/[chargeId]`(청구 확인+토스 위젯), `/tenant/pay/success·fail`, `/tenant/payments` 이력
- **완료 기준**: 세입자 홈 「자리페이로 결제」 → 위젯 → 성공 화면 → 원장 반영까지 완주. 부분납부 청구는 잔액만 결제
- **최소 테스트**: checkout — 남의 청구 403, PAID 청구 409, 금액=잔액 검증
- **통합 테스트**: **E2E** 세입자 로그인 → 9월 청구 결제(테스트 카드) → 성공 화면 → 임대인 계정에서 완납 확인

## ⬜ T2.3 환급 계산기

- **내용**: 공제율 상수 테이블(연도별) + 계산 함수 + `POST /api/refund/calculate` + `/refund/calculator`(비로그인, SEO 메타)
- **완료 기준**: 입력→연도별 산출 내역+합계 표시, 비로그인 CTA는 가입 유도
- **최소 테스트**: **계산 핵심.** 경계값 — 총급여 5,500만(17%)/5,500 초과(15%)/8,000 초과(0), 월세 연 1,000만 한도 컷, 5년 소급 연도 산정, 거주기간 부분 연도
- **통합 테스트**: 없음 (단위로 충분)

## ⬜ T2.4 환급 신청

- **내용**: refunds CRUD(DRAFT→SUBMITTED), `POST /api/uploads`(D3), `/tenant/refund/apply`(계약 자동 채움, 서류 슬롯), `/tenant/refund`(상태 스테퍼)
- **완료 기준**: 임시저장→제출→상태 추적이 화면에서 완주, 보완요청 시 추가 업로드 가능
- **최소 테스트**: 제출 시 필수 서류 검증, DRAFT 아닌 신청 수정 거부, 업로드 타입·크기 제한
- **통합 테스트**: (T2.5와 묶음)

## ⬜ T2.5 어드민 환급 심사 큐

- **내용**: `/refunds`(admin) — 상태 필터·심사 상세·서류 뷰어, 액션(심사시작/승인/반려/보완요청+코멘트) → 세입자 알림톡 시뮬 발송
- **완료 기준**: 심사 액션마다 상태·심사자·시각 기록, 세입자 화면 스테퍼에 반영
- **최소 테스트**: 액션 상태 머신 — SUBMITTED에서만 심사시작 가능 등 허용 전이표 검증, 비어드민 403
- **통합 테스트**: **E2E** 세입자 신청 제출 → 어드민 보완요청 → 세입자 추가 업로드 → 승인 → 스테퍼 완료 표시

## ⬜ T2.6 민원 접수·스레드

- **내용**: complaints CRUD+messages, `/tenant/complaints`(접수·목록), 스레드 화면(세입자·임대인), 임대인 상태 변경
- **완료 기준**: 세입자 접수 → 임대인 홈 배지 → 스레드 왕복 → 해결 처리 완주 (작업 전환 버튼은 Phase 5에서 활성화)
- **최소 테스트**: 스레드 작성 권한 — 해당 계약의 세입자·임대인만, 제3자 403
- **통합 테스트**: E2E — 민원 접수 → 임대인 답변 → 해결 → 세입자 화면 상태 확인
