> **클린 체크아웃 함정**: `packages/db/src/generated`(prisma client)와 `styled-system/`(panda)은
> gitignore 된 코드젠 산출물이다. `check` job 의 `pnpm build` 가 만들지만 job 사이에 파일이
> 공유되지 않아 `test` job 이 `Cannot find module './generated/client'` 로 죽었다.

> `next dev` 를 직접 부르면 web 의 dev 스크립트를 건너뛰기 때문이다.

## CI 가 로컬과 다른 점 (두 번 데었다)

`.env.local` 은 gitignore 라 **CI 에는 없다.** 로컬에서만 통과하는 테스트가 나오는 원인이 두 번 다 이것이었다.

| 겪은 일 | 원인 | 대응 |
|---|---|---|
| `Cannot find module './generated/client'` | 코드젠 산출물이 job 간에 공유되지 않음 | test job 앞에 `pnpm codegen` |
| 토스 위젯 iframe 이 안 그려짐 (T2.1·T2.2 E2E) | `NEXT_PUBLIC_TOSS_CLIENT_KEY` 가 CI 에 없음 | 워크플로 `env` 에 추가(문서 공개 키라 시크릿 아님) |

**새 환경변수를 쓰는 코드를 추가하면 `.github/workflows/ci.yml` 의 `test` job `env` 에도 넣어야 한다.**
실제 자격증명(예: `BLOB_READ_WRITE_TOKEN`)이면 GitHub Secrets 를 쓴다.
