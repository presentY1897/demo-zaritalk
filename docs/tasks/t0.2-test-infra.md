## CI 가 로컬과 다른 점 (두 번 데었다)

`.env.local` 은 gitignore 라 **CI 에는 없다.** 로컬에서만 통과하는 테스트가 나오는 원인이 두 번 다 이것이었다.

| 겪은 일 | 원인 | 대응 |
|---|---|---|
| `Cannot find module './generated/client'` | 코드젠 산출물이 job 간에 공유되지 않음 | test job 앞에 `pnpm codegen` |
| 토스 위젯 iframe 이 안 그려짐 (T2.1·T2.2 E2E) | `NEXT_PUBLIC_TOSS_CLIENT_KEY` 가 CI 에 없음 | 워크플로 `env` 에 추가(문서 공개 키라 시크릿 아님) |
| 같은 스펙이 CI 에서만 타임아웃 | Playwright **기본 테스트 예산 30초** < 스펙 안의 의도적 대기(위젯 30초) | `playwright.config.ts` 에 `timeout`(CI 120초)·`expect.timeout` 명시 |
| `refund-apply.spec.ts` 의 클릭이 CI 에서만 `intercepts pointer events` 로 영영 재시도 (T2.4) | **CI 러너에 「Malgun Gothic」이 없다.** 폰트 폴백(DejaVu Sans)이 넓어 `input[type="date"]` 최소 폭이 172→182px 이 되고, `repeat(2, 1fr)`(=`minmax(auto,1fr)`) 두 칸이 393px 셸을 뚫는다 → 크로뮴 모바일 에뮬레이션이 화면을 축소(레이아웃 뷰포트 393→**406**, page scale ≈0.97) → Playwright 의 CSS 좌표와 실제 이벤트 지점이 **스크롤한 만큼** 벌어져 아래쪽 버튼 클릭이 `<main>`·하단 탭바에 떨어진다 | 격자를 `repeat(2, minmax(0, 1fr))` + 자식 `minW: 0` 으로 줄어들 수 있게. 스펙에 `expectFitsShell()` 가로 오버플로 감시 추가 |

> **규칙**: 스펙 안에서 `{ timeout: N }` 으로 오래 기다린다면, 그 N 은 **테스트 예산보다 작아야 한다.** 외부 서비스를 기다리는 대기를 넣을 때는 예산도 함께 확인하라.

> **규칙**: 모바일 셸(393px)에서 **가로로 넘치는 화면을 만들지 마라.** 넘치면 크로뮴이 페이지를
> 축소해 버리고, 그때부터 Playwright 클릭 좌표가 어긋나 원인을 알 수 없는 타임아웃이 난다.
> 특히 `grid`/`flex` 의 `1fr` 은 내용 최소 폭 아래로 줄지 않는다 — `input[type="date"]`,
> `white-space: nowrap` 처럼 **폰트에 따라 최소 폭이 변하는 요소**를 나란히 둘 때는
> `minmax(0, 1fr)` + `min-width: 0` 을 쓴다. 로컬은 한글 폰트가 깔려 있어 드러나지 않는다.
>
> 재현 방법: 사용자 폰트 디렉터리를 뺀 fontconfig 를 만들어 `FONTCONFIG_FILE` 로 지정하고
> E2E 를 돌리면 CI 와 같은 폴백 폰트가 잡힌다(`<fontconfig><dir>/usr/share/fonts</dir></fontconfig>`).
>
> **아직 남은 같은 함정**: `features/lease/LeaseForm.tsx` 의 `twoColStyle` 도 날짜 두 칸이라
> 같은 조건에서 `/landlord/leases/new` 가 406px 로 벌어진다(현재는 그 스펙의 클릭이 화면 위쪽이라
> 살아 있을 뿐이다). T1.2 소유라 손대지 않았다.
