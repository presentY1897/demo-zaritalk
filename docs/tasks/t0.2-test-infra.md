> **클린 체크아웃 함정**: `packages/db/src/generated`(prisma client)와 `styled-system/`(panda)은
> gitignore 된 코드젠 산출물이다. `check` job 의 `pnpm build` 가 만들지만 job 사이에 파일이
> 공유되지 않아 `test` job 이 `Cannot find module './generated/client'` 로 죽었다.
> 루트 `pnpm codegen`(prisma generate + ui·web·admin panda codegen)을 test job 앞에 둔다.
> 같은 이유로 Playwright `webServer` 도 `next dev` 앞에 panda codegen 을 붙였다 —
> `next dev` 를 직접 부르면 web 의 dev 스크립트를 건너뛰기 때문이다.
