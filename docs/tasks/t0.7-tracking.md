## 이벤트 네이밍 규약 — `<domain>_<object>_<action>`

- 소문자·숫자만, 마디는 `_` 로 구분. 2~4마디(`page_view` ~ `payment_toss_confirm_success`).
- `<domain>` 은 화면이 아니라 **도메인**(notice·signup·payment·refund…).
- `<object>` 는 생략 가능 — 대상이 도메인 자체면 `signup_start` 처럼 2마디.
- `<action>` 은 현재형 동사(`view`·`click`·`start`·`complete`·`submit`).
- 서버가 정규식 `^[a-z][a-z0-9]*(?:_[a-z0-9]+){1,3}$` 으로 검증하고 어긋나면 **400**.
- 새 이벤트는 **`events.ts` 에 상수를 먼저 추가**하고 그 상수를 쓴다. 화면에 문자열을 직접 적지 않는다.

### 미리 정의한 이벤트 상수 (`@/lib/tracking/events`)

| 상수 | 이름 | 언제 |
|---|---|---|
| `TRACK_EVENTS.PAGE_VIEW` | `page_view` | 라우트 전환마다 **자동 수집**(직접 호출 불필요) |
| `TRACK_EVENTS.NOTICE_VIEW` | `notice_view` | 공개 고지서 페이지 노출 (T1.8) |
| `TRACK_EVENTS.NOTICE_CTA_CLICK` | `notice_cta_click` | 고지서 하단 가입 CTA 클릭, `props.variant` 에 A/B 변형 (T1.8) |
| `TRACK_EVENTS.SIGNUP_START` | `signup_start` | 가입 시작 — 인증 요청 (T0.4) |
| `TRACK_EVENTS.SIGNUP_COMPLETE` | `signup_complete` | 가입 완료 (T0.4) |
| `TRACK_EVENTS.PROFILE_SWITCH_OPEN` | `profile_switch_open` | 프로필 전환 시트 열기 (T0.5) |
| `TRACK_EVENTS.PROFILE_SWITCH_COMPLETE` | `profile_switch_complete` | 프로필 전환 성공 — props `{ from, to }` (T0.5) |

뒤 4개가 [D2](../DECISIONS.md#-d2-ab-실험-소재-1개-실운영) 의 A/B 퍼널 `notice_view → notice_cta_click → signup_start → signup_complete` 다. T1.8·T6.1 은 이 상수를 그대로 쓴다.

## `useTrack()` 사용법

```tsx
"use client";
import { useTrack } from "@zari/ui";
import { TRACK_EVENTS } from "@/lib/tracking/events";

export function NoticeCta({ variant }: { variant: "A" | "B" }) {
  const { track } = useTrack();
  return (
    <button onClick={() => track(TRACK_EVENTS.NOTICE_CTA_CLICK, { variant })}>
      가입하고 내 고지서 받기
    </button>
  );
}
```

- `track(name, props?)` — 큐에 넣는다. 400ms 배치 창으로 묶여 나가고, 탭이 숨겨지거나(`visibilitychange`) 페이지를 떠날 때(`pagehide`) 자동 flush 된다.
- `flush()` — 큐를 즉시 보낸다. `window.location.href = ...` 처럼 **전체 페이지 이동 직전**에만 필요하다(클라이언트 라우팅은 큐가 유지되므로 불필요).
- 전송은 `navigator.sendBeacon` 우선, 없거나 큐가 꽉 차면 `fetch(..., { keepalive: true })` 폴백. 실패해도 화면에 영향을 주지 않는다(에러를 삼킨다).
- `path`(현재 경로)와 `sessionId`(탭 단위, sessionStorage)는 훅이 자동으로 채운다.
- Provider 밖에서 불러도 예외 없이 no-op — 트래킹 때문에 화면이 죽지 않는다.

## anonId 쿠키

- 이름 `zari_anon`, 32자 hex, **1년**, `Path=/`, `SameSite=Lax`, 프로덕션에서 `Secure`.
- **서버(proxy)가 `Set-Cookie` 로 굽는 1st-party 쿠키** — `document.cookie` 로 굽는 쿠키가 Safari ITP에서 7일 만에 만료되는 문제를 피한다.
- **`httpOnly=false`** — anonId는 인증 수단이 아니라 "이 브라우저" 라벨이라 노출돼도 권한이 따라오지 않고, A/B 배정(T6.2)·클라이언트 진단에서 읽을 수 있어야 한다. 로그인 세션 토큰(`zari_session`, T0.3)은 반대로 `httpOnly` — 둘을 섞지 않는다.
- proxy matcher는 `_next/static`·`_next/image`·`favicon.ico`·`robots.txt`·`sitemap.xml`·확장자가 붙은 정적 자산을 제외한 전 경로(API 포함).
- `POST /api/track` 은 anonId를 ① 요청 본문 ② 쿠키 ③ 서버 발급 순으로 정하고 **요청을 버리지 않는다.** ③일 때만 응답에 `Set-Cookie` 를 실어 다음 요청부터 이어지게 한다.
