# T4.1 커뮤니티 보드

> Phase 4 · 상태: ⬜ · [Phase 구성](../PHASES.md)

| 라우트 | 화면·기능 |
|---|---|
| `/community` | 지역 보드 — 시군구 선택, 최신/인기(likeCount) 탭, 무한 스크롤(커서), 글쓴이 프로필 유형 배지 |
| `/community/write` | 글 작성 — 지역·제목·본문 |
| `/community/[postId]` | 상세 — 조회수, 좋아요 토글, 댓글 작성·삭제, 글·댓글 신고(사유). 블라인드 글 표시 |

| 엔드포인트 | 동작 |
|---|---|
| `GET·POST /api/posts` | 목록(region+sort+cursor)·작성, `GET·PATCH·DELETE /[id]` — 조회 시 viewCount 증가 |
| `POST·DELETE /api/posts/[id]/like` | 토글(likeCount 비정규화 갱신) |
| `GET·POST /api/posts/[id]/comments` | 댓글, `DELETE /api/comments/[id]` |

- **완료 기준**
  - [ ] 글·댓글·좋아요 완주, 인기 탭 정렬, 유형 배지 표시
- **테스트** — 최소: 커서 페이지네이션 경계·중복 없음 · 좋아요 토글 멱등·likeCount 일치 / 통합: E2E 글 작성→다른 계정 좋아요·댓글→인기 탭 반영
