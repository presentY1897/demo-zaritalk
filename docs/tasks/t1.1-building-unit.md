# T1.1 건물·호실 관리

> Phase 1 · 상태: ⬜ · [Phase 구성](../PHASES.md)

| 라우트 | 화면·기능 |
|---|---|
| `/landlord/buildings` | 건물 목록(호실 수·공실 수 요약) |
| `/landlord/buildings/[id]` | 건물 상세 — 호실 그리드(계약중/공실/연체 상태 색), 호실 추가·수정 |
| `/landlord/units/[id]` | 호실 상세 — 현재 계약 카드, 과거 이력, 공실이면 「매물 등록」(T3.1)·「중개 요청」(T3.6) 버튼 |

| 엔드포인트 | 동작 |
|---|---|
| `GET·POST /api/buildings` | 내 건물 목록·생성, `PATCH·DELETE /api/buildings/[id]` |
| `POST /api/buildings/[id]/units` | 호실 추가, `GET·PATCH /api/units/[id]` — 상세엔 계약·매물·수납 요약 포함 |

- 주소 입력은 카카오 키 전까지 수동(주소 문자열+지도 클릭 좌표), 키 수령 후 주소 검색으로 교체
- **완료 기준**
  - [ ] 건물→호실 등록·수정·삭제 화면 완주, 그리드에 상태 색 표시
- **테스트** — 최소: 호실 `@@unique([buildingId,label])` 중복 409 · 타인 건물 403
