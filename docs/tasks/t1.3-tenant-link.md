# T1.3 세입자 연결

> Phase 1 · 상태: ⬜ · [목차](./README.md)

- **플로우**: ①임대인 계약 등록(전화번호 포함) → PENDING_TENANT ②세입자가 같은 번호로 가입/로그인 → `tenantPhone` 매칭 계약 노출 ③수락 → `tenantProfileId`·`tenantAcceptedAt` 기록, ACTIVE 전환

| 라우트 | 화면·기능 |
|---|---|
| `/tenant/leases/accept` | 대기 계약 목록 → 조건 확인 → 수락/거절 |
| `/tenant` | 세입자 홈 — 내 계약 카드, 이번 달 납부 상태 + 「자리페이로 결제」(T2.2), 환급 배너, 민원 진입 |

| 엔드포인트 | 동작 |
|---|---|
| `GET /api/tenant/pending-leases` | 내 전화번호 매칭 대기 계약 |
| `POST /api/leases/[id]/accept` | 수락(거절은 `/decline`) |

- **완료 기준**
  - [ ] 시드 홍미가 번호(01055555555)로 가입 → 대기 계약 → 수락 → ACTIVE + 세입자 홈 표시
