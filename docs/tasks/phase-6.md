# Phase 6 — 그로스 마무리·대시보드

> 스펙: [§12 그로스](../specs/12-growth.md) · [§13 백오피스](../specs/13-admin.md)
> 선행 조건: D2(A/B 소재) 결정

## ⬜ T6.1 A/B 실험 실운영

- **내용**: `GET /api/ab/[experimentKey]`(anonId 해시 고정 배정) + 공개 고지서 CTA 2안 적용(D2), 노출·클릭 이벤트 연결
- **완료 기준**: 같은 브라우저는 항상 같은 변형, 변형별 이벤트가 구분 수집됨
- **최소 테스트**: **배정 핵심.** ①해시 배정 결정성(같은 anonId=같은 변형) ②분포 대략 50:50(대량 샘플) ③로그인 후 userId 연결 유지
- **통합 테스트**: E2E — 두 개의 신규 브라우저 컨텍스트에서 각자 변형 고정 확인

## ⬜ T6.2 어드민 지표 대시보드·퍼널

- **내용**: `/api/admin/metrics/overview`(가입·DAU·수납률·발송·열람률·결제액·환급 현황) + `/funnel`(notice 퍼널 변형별) + 어드민 홈 대시보드·차트
- **완료 기준**: 시드+E2E로 쌓인 실데이터가 차트에 표시, 퍼널이 변형별 전환율로 분리
- **최소 테스트**: 집계 쿼리 — 수납률(청구 대비 납부) 계산, 퍼널 단계 카운트(중복 anonId 제거)
- **통합 테스트**: 없음 (API 테스트로 충분)

## ⬜ T6.3 어드민 조회 화면 일괄

- **내용**: `/users`(검색·상세 타임라인), `/leases`·`/charges`(필터·연체 드릴다운), `/messages`(발송 이력), `/events`(이벤트 탐색+시간대 차트)
- **완료 기준**: 전 화면 서버 페이지네이션·필터 동작, 비어드민 접근 차단
- **최소 테스트**: admin 미들웨어 가드 — isAdmin 아닌 세션 403
- **통합 테스트**: 없음

## ⬜ T6.4 SEO 마무리

- **내용**: 공개 페이지(고지서·매물·환급 계산기) 메타·OG·JSON-LD 점검, sitemap.xml·robots.txt
- **완료 기준**: Lighthouse SEO 90+ (공개 페이지 3종)
- **최소 테스트**: sitemap에 공개 라우트 포함 검증
- **통합 테스트**: 없음

## ⬜ T6.5 문서·마무리

- **내용**: README(아키텍처 다이어그램, 데모 계정, 로컬 실행·배포 가이드), specs 상태줄 최종 갱신, 데모 시나리오 대본(시연 순서)
- **완료 기준**: README만 보고 클론→실행→데모 로그인이 가능
- **최소 테스트**: 없음
- **통합 테스트**: 전체 E2E 스위트 최종 green (회귀 확인)
