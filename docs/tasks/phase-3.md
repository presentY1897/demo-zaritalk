# Phase 3 — 매물·중개·통근

> 스펙: [§7 매물·통근](../specs/07-listing-commute.md) · [§8 중개 매칭](../specs/08-brokerage.md)
> 선행 조건: 카카오 디벨로퍼스 키(맵 JS+모빌리티 REST), ODsay LAB 키(사용자)

## ⬜ T3.1 매물 등록

- **내용**: listings CRUD + `/landlord/units/[id]/listing`(등록·수정·상태 변경), 사진 업로드(D3 저장소 재사용)
- **완료 기준**: 공실 호실에서 매물 등록 → OPEN, 상태 변경(RESERVED/CLOSED) 반영
- **최소 테스트**: 권한 — 소유 임대인·수락 중개인만 등록 가능, 계약중 호실 등록 409
- **통합 테스트**: (T3.2와 묶음)

## ⬜ T3.2 지도 탐색

- **내용**: `GET /api/listings?bounds=&filters=` + `/search` — 카카오맵 핀+가격 라벨, 하단 스냅 시트 리스트, 이동 시 재조회, 전월세·금액 필터
- **완료 기준**: 지도 이동·필터 변경이 리스트와 동기화, 비로그인 접근 가능
- **최소 테스트**: bounds 쿼리 — 영역 내/외 필터 정확성, OPEN만 노출, 필터 조합
- **통합 테스트**: **E2E** 매물 등록 → `/search`에서 핀·리스트 노출 → 상세 진입

## ⬜ T3.3 매물 상세 + SEO

- **내용**: `/listings/[id]` — 사진·조건·위치 지도·문의(더미), 메타·OG·구조화 데이터
- **완료 기준**: 비로그인 접근, OG 태그·JSON-LD 유효
- **최소 테스트**: 없음 (렌더 확인)
- **통합 테스트**: 없음

## ⬜ T3.4 근무지 관리

- **내용**: workplaces CRUD + `/tenant/workplaces`(주소 검색→좌표, 복수 등록)
- **완료 기준**: 등록한 근무지가 통근 조회의 기준점으로 노출
- **최소 테스트**: 좌표 범위 검증, 본인 프로필 것만 CRUD
- **통합 테스트**: (T3.5와 묶음)

## ⬜ T3.5 통근시간 조회

- **내용**: `POST /api/commute` — CommuteCache 확인 → 미스 시 ODsay(대중교통)·카카오모빌리티(자동차) 병렬 호출 → upsert. 매물 상세 「내 근무지까지」 버튼 + 목록·핀 배지(캐시 히트분)
- **완료 기준**: 상세에서 조회한 결과가 목록 배지로 재사용됨, 한쪽 API 실패해도 부분 결과 표시
- **최소 테스트**: **매칭 핵심.** ①캐시 히트 시 외부 호출 없음 ②미스 시 upsert ③외부 한쪽 실패 → 부분 결과 저장 ④양쪽 실패 → 에러 응답·캐시 미생성. 외부 API mock
- **통합 테스트**: **E2E** 근무지 등록 → 매물 상세 통근 조회 → 목록 복귀 시 배지 표시 (키 없으면 skip)

## ⬜ T3.6 중개 요청·반경 매칭

- **내용**: `POST /api/brokerage-requests`(반경 내 거리순 20명 선정→타겟+알림 생성), `GET /preview`, 요청 시트(대상 미리보기), `/landlord/brokerage` 현황
- **완료 기준**: 시드 중개인(왕십리, 3km)이 행당해피빌 요청의 대상에 포함, 발송 후 현황 표시
- **최소 테스트**: **매칭 핵심.** ①하버사인 거리 계산 ②반경 밖 제외 ③21명 이상일 때 거리순 20명 컷 ④중복 요청 대상 유니크
- **통합 테스트**: (T3.7과 묶음)

## ⬜ T3.7 중개인 수신함·수락

- **내용**: `GET /api/realtor/inbox`, `POST /api/brokerage-targets/[id]/respond`, `/realtor` 수신함, `/realtor/requests/[id]` 상세, `/realtor/listings`
- **완료 기준**: 열람 시 VIEWED, 수락 시 임대인 알림+매물 등록 권한, 첫 수락 시 요청 MATCHED
- **최소 테스트**: respond 상태 전이 — SENT→VIEWED→ACCEPTED/DECLINED만 허용, 타 중개인 타겟 403
- **통합 테스트**: **E2E** 임대인 공실 중개 요청 → 중개인 수신함 확인 → 수락 → 해당 호실 매물 등록 → `/search` 노출
