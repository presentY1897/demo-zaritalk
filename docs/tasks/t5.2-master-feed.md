# T5.2 마스터 의뢰 피드 — pull + 유료 push 추천

> Phase 5 · 상태: ⬜ · [Phase 구성](../PHASES.md)

[D4 확정](../DECISIONS.md#-d4-마스터-매칭-방식--pull--push-하이브리드): **pull 피드(전 마스터) + push 추천(유료 PRO 마스터)** 을 함께 구현한다.

| 라우트/API | 동작 |
|---|---|
| `/master` | 홈 — 탭 2개. **추천받은 의뢰**(push, PRO 전용) / **전체 피드**(pull, 내 업종 포함 + 활동반경 내 REQUESTED 거리순) |
| `/master/orders/[id]` | 상세 — 금액·메시지로 견적 제안(의뢰당 1회) |
| `GET /api/master/feed` | pull — 업종+반경 매칭 피드(거리순) |
| `GET /api/master/targets` | push — 나에게 발송된 `WorkOrderTarget` 목록(최신순). FREE 플랜이면 빈 목록 + 업그레이드 안내 |
| `POST /api/master/plan` | 데모용 플랜 전환(FREE ↔ PRO) — 유료 결제 없이 토글, 추천 동작을 시연하기 위함 |

**선행 스키마 변경** (이 task에서 마이그레이션)

- `enum MasterPlan { FREE PRO }`, `MasterDetail.plan`(기본 `FREE`) · `MasterDetail.planUntil DateTime?`
- `model WorkOrderTarget` — `BrokerageTarget` 과 동형: `workOrderId` · `masterProfileId` · `distanceKm` · `status` · `sentAt`, `@@unique([workOrderId, masterProfileId])`
- 시드: 최마스를 PRO 로 두고, 무료 마스터 1명(예: 한마스, 성수 INTERIOR)을 추가해 pull/push 차이가 화면에 보이게 한다

- **완료 기준**
  - [ ] 시드 마스터(성수, REPAIR·CLEANING, 5km) 전체 피드에 행당해피빌 수리 의뢰 노출
  - [ ] PRO 마스터는 의뢰 생성 즉시 추천 탭에 해당 의뢰가 보이고, FREE 마스터는 추천 탭이 비어 있음(업그레이드 안내)
  - [ ] 플랜 토글 후 추천 탭이 즉시 채워짐(데모 시연용)
- **테스트** — 최소: pull — 업종 불일치 제외 · 반경 밖 제외 · REQUESTED만 / push — FREE 마스터는 타겟 미생성 · PRO만 거리순 N명 · 동일 의뢰 재발송 시 중복 타겟 없음(unique)
