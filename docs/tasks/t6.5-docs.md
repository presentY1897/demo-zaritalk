# T6.5 문서·마무리

> Phase 6 · 상태: ✅ · [Phase 구성](../PHASES.md)

## 한 일

- **README** — 라이브 URL·규모·문서 링크, **데모 시나리오**(역할별 시연 경로 + 비로그인 화면),
  테스트 실행법, **알려진 한계**를 넣었다. 처음 보는 사람이 이 파일만으로 무엇을 어떻게
  시연할지 알 수 있어야 한다는 기준으로 썼다.
- **알려진 한계**를 한곳에 모았다 — 각 task 가 "스키마가 필요했지만 안 만든 것" 으로 흩어 놓은
  것 중 **시연·평가에 영향을 주는 것**만 골랐다. 숨기는 것보다 근거와 함께 드러내는 편이 낫다.

## 데모 시나리오 (README 와 동일)

| 역할 | 번호 | 시연 |
|---|---|---|
| 임대인 | `01011111111` | 연체 1건 1,015,500원 → 가상 입금 → 완납 → 고지서 발송 |
| 세입자 | `01022222222` | 이번 달 납부 → 자리페이 카드결제 → 임대인 원장 즉시 반영 |
| 중개인 | `01033333333` | 중개 요청 열람 → 수락 → 매물 등록 → `/search` 노출 |
| 마스터(PRO) | `01044444444` | 추천 탭에 의뢰 노출 → 견적 → 임대인 수락 |
| 마스터(무료) | `01066666666` | 추천 탭 비어 있음 — 유료 차이 시연 |
| 관리자 | `01000000000` | 백오피스(전화번호 + `ADMIN_PASSWORD`) |

비로그인: `/notice/demo-notice-hong`(공개 고지서·A/B) · `/search` · `/refund/calculator` · `/deals`

## 남긴 한계와 근거

| 한계 | 근거 |
|---|---|
| 대중교통 통근시간 **모의** | [D9](../DECISIONS.md) — 알고리즘이 아니라 데이터(전국 통합 GTFS 부재)가 막는다. ODsay 키가 오면 제공자 한 줄 교체 |

| 토스 키가 **문서 공개 체험용** | 사용자 대시보드에 안 잡힌다. 환경변수 2개 교체로 전환 |
| 프리뷰도 **같은 Neon DB** | 브랜치별 DB 분리는 범위 밖([DEPLOY.md](../DEPLOY.md)) |
| 시드 금액이 **2026-06~09 고정** | 그 창을 벗어나면 어드민 수납률·결제액 차트가 빈다(T6.2) |
| 퍼널 차트는 **시드 데이터가 없다** | `AbAssignment`·`TrackingEvent` 시드가 없어 실제 방문으로만 채워진다(T6.2) |
