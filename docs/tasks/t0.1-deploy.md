## CI에서 한 번 깨진 것 (기록)

`test` job이 `Cannot find module './generated/client'` 로 전부 실패했다. `packages/db/src/generated`(prisma client)와 `styled-system/`(panda)은 gitignore 된 **코드젠 산출물**인데, `check` job의 `pnpm build`가 만든 결과는 다른 job으로 전달되지 않는다. 루트 `pnpm codegen` 을 test job 앞에 두어 해결했다. **Vercel도 같은 함정이 있어** `vercel.json` 이 레포 루트에서 `turbo run build --filter=<app>...` 을 돌리도록 잡아 뒀다(의존 패키지의 codegen 포함).
