# T1.9 임대인 홈 대시보드

> Phase 1 · 상태: ⬜ · [Phase 구성](../PHASES.md)

| 라우트/API | 동작 |
|---|---|
| `/landlord` | 이번 달 수납 현황(건수·금액), 연체 리스트, 만기 3개월 이내 카드, 미확인 민원·견적 배지 |
| `GET /api/landlord/summary` | 대시보드 집계 |

- **완료 기준**
  - [ ] 시드 기준 숫자 정확(연체 1건 **1,015,500원** / 이번 달 예정 등)

> 연체 금액은 원장 엔진(T1.4) 규칙으로 계산된 값이다 — 이월 300,000 + 연체료 15,500(31일 일할) + 월세 650,000 + 관리비 50,000.
> "연체"는 `status === "OVERDUE"`(한 푼도 안 낸 청구)를 뜻한다. 부분납까지 포함한 넓은 미납은 `isDelinquent()` 로 따로 센다 — **두 숫자가 다르다.**
- **테스트** — 최소: 연체 건수·금액, 만기 90일 필터 집계
