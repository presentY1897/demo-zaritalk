# T1.5 수납 UI

> Phase 1 · 상태: ⬜ · [Phase 구성](../PHASES.md)

| 라우트 | 화면·기능 |
|---|---|
| `/landlord/leases/[id]` 수납 탭 | 월별 청구 리스트 — 내역(월세+관리비+이월+연체료)·납부액·상태 배지, 행 탭 → 청구 시트 |
| 청구 상세 시트 | 납부 타임라인, 「받음 체크」(금액 입력 → 부분납부), 「가상 입금 시뮬레이션」(입금자명·금액 → 즉시 반영), 고지서 재발송 |

| 엔드포인트 | 동작 |
|---|---|
| `GET /api/leases/[id]/charges` | 청구 목록(납부 기록 포함) |
| `POST /api/charges/[id]/payments` | 납부 추가 — `MANUAL_CHECK \| VIRTUAL_TRANSFER`, 상태 재계산 |
| `DELETE /api/payments/[id]` | 오기록 취소(상태 재계산) |

- **완료 기준**
  - [ ] 시드 6~9월 4개 상태(완납/부분납/연체/예정) 구분 표시, 가상 입금 즉시 반영
- **테스트** — 최소: 초과 납부 400 · 부분납 누적 후 완납 전이 · 삭제 시 재계산 / 통합: **E2E** 8월 연체 청구 전액 가상 입금 → 완납 배지 + 대시보드 연체 수 감소
