# §13 백오피스 (apps/admin, 데스크톱)

> 상태: ⬜ 미착수 · [전체 목차](../SPEC.md)

로그인: `User.isAdmin` 계정만(같은 OTP 인증 + 데모 어드민 원클릭). 사이드바 레이아웃, 전 화면 서버 페이지네이션·필터.

각 업무화면은 관련 기능과 같은 Phase에서 세트로 구현한다(환급 심사 → Phase 2, 신고 처리 → Phase 4) **[제안]**.

| 라우트 | 화면·기능 |
|---|---|
| `/` | **지표 대시보드** — 가입자·DAU 추이(TrackingEvent 기반), 수납률(청구 대비 납부, 월별), 고지서 발송·열람률, 결제액 추이, 환급 신청 파이프라인 현황, **A/B 퍼널 차트**(notice_cta 변형별 전환율). |
| `/refunds` | **환급 심사 큐**([§6](./06-refund.md)) — 상태 필터(제출/심사중/보완요청), 상세: 신청 정보·산출 내역·서류 뷰어, 액션: 심사시작/승인/반려/보완요청(코멘트 필수) → 상태 변경 시 세입자에게 알림톡 시뮬. |
| `/reports` | **신고 처리**([§10](./10-community.md)) — 대기 신고 목록, 대상 글/댓글 미리보기, 액션: 블라인드(soft delete)/기각. 처리자·시각 기록. |
| `/messages` | 발송 이력 전체 — 종류·수신자 필터, 열람 여부, 본문 미리보기(알림톡 스타일). |
| `/users` | 회원 조회 — 검색(이름·전화), 상세: 프로필들·계약·신청 이력 타임라인. |
| `/leases` `/charges` | 계약·수납 조회 — 상태 필터, 연체 계약 드릴다운. |
| `/events` | 이벤트 로그 탐색 — 이름·기간 필터, 시간대별 카운트 차트. |

어드민 API는 `/api/admin/*` 네임스페이스로 분리, isAdmin 미들웨어 가드. 대시보드 집계는 각 1개 엔드포인트(`/api/admin/metrics/overview`, `/funnel`)로 묶음.

## 완료 기준

- [ ] 전 화면 서버 페이지네이션·필터 동작, 비어드민 접근 차단
- [ ] 대시보드에 시드+E2E 실데이터 표시, 퍼널이 A/B 변형별 전환율로 분리
- [ ] 환급 심사([§6](./06-refund.md))·신고 처리([§10](./10-community.md))의 완료 기준은 각 스펙 참조

## 테스트

- **최소(단위·API)**: admin 미들웨어 가드 — isAdmin 아닌 세션 403 · 집계 — 수납률(청구 대비 납부) 계산·퍼널 단계 카운트(anonId 중복 제거)
- **통합**: 없음 (API 테스트로 충분 — 심사·모더레이션 E2E는 §6·§10에 포함)
