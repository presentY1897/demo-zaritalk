# §14 배치·크론 (Vercel Cron)

> 상태: ⬜ 미착수 · [전체 목차](../SPEC.md)

| 작업 | 주기·동작 |
|---|---|
| 청구 생성·연체 처리 | 매일 — ACTIVE 계약의 당월 청구 생성(멱등, [§3](./03-rent-ledger.md) 원장 규칙), 납부일 경과분 OVERDUE 전환, 이월·연체료 반영. 데모 시연용으로 어드민에서 수동 트리거 버튼도 제공. |
| 만기 임박 알림 | 매일 — 만기 90일 전 계약에 CONTRACT_EXPIRY 알림톡 시뮬 1회 발송([§4](./04-notice.md)). |
| 실거래가 수집 | 매일 — 알림 구독·최근 조회 지역의 당월 데이터 수집 → 신규 거래 시 구독자에게 알림([§11](./11-real-transaction.md)). |

## 완료 기준

- [ ] 매일 크론이 청구 생성·연체 전환·이월·연체료를 처리(멱등 — 원장 규칙은 [§3](./03-rent-ledger.md)), 어드민 수동 트리거 제공
- [ ] 만기 90일 전 계약에 CONTRACT_EXPIRY 알림 1회만 발송(중복 없음)
- [ ] 실거래가 수집이 구독·최근 조회 지역 대상으로 동작

## 테스트

- **최소(단위·API)**: 크론 엔드포인트 2회 연속 실행 멱등(청구·만기 알림 모두) · 크론 인증(시크릿 헤더) 없는 호출 401
- **통합**: 크론 실행 후 DB 상태 검증은 §3·§11 테스트에 포함
